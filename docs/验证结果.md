## 不能由这些测试推出的结论

尚未对用户已登录的真实 AI Studio 网页发送测试消息。模拟网页能检验扩展执行逻辑，但不能证明 Google 当前的前端事件绑定、上传组件和流式状态与推断完全一致。

首次真实使用建议创建一个 2 对话、每个 1 轮的小组，第 1 轮放短文字，第 2 轮放短文字和一张图片，验证模型、系统指令、上传、自动切换和下载。这是现场联调步骤，不是额外 API 配置。

现有 DOM 包仍缺少图片正在上传、配额报错和浏览器重启后的上下文恢复状态；集成测试使用模拟页面验证了独立会话 URL 的记录、重开和防重复发送，但真实 AI Studio 是否能从某个 URL 完整恢复上下文仍由网站自身决定。真实网页中的连续多轮和异常恢复仍是优先观察的兼容边界。无法确认时，本版会暂停并保留既有结果。
